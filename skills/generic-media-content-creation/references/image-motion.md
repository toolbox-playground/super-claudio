# Animating Static Images

Tools that take a still image and add realistic motion to it.

## Weavy AI (now Figma Weave) — Motion from Photo

Figma acquired Weavy in late 2025 and relaunched it as **Figma Weave** (weave.figma.com) — same node-based canvas and workflows, now integrated with Figma's broader design/billing ecosystem. Adds realistic motion to a static photograph (person moves, fabric flows, hair blows).

- Great for: fashion images, lifestyle photos, product ads where a model wears/uses the product
- Input: photo + motion direction prompt
- Output: short looping or progressive video clip
- Common use case: animate an ecommerce model photo → use in TikTok Shop

**Workflow:**
1. Prepare a clean product/model photo
2. Upload to Figma Weave (weave.figma.com)
3. Describe the desired motion: "model turns and smiles", "dress flows in wind", "product rotates slowly"
4. Generate and download as MP4

## Kling 3.0 "Image to Video" — High Quality Motion

Kling's image-to-video mode is also excellent for animating photos. Kling 3.0 / Image 3.0 (launched Feb 2026) added native 2K/4K output and native audio generation; Kling 3.0 Turbo (faster/cheaper) and a Kling O3 upgrade (stronger prompt adherence and reference consistency) followed in Jun 2026.

- URL: klingai.com → Image to Video tab
- Higher quality than many tools; clips run roughly 3–15 seconds with synced audio
- Supports longer clips from a single image

## Runway Gen-4.5 — Image to Video

- URL: runwayml.com
- Professional-grade animation from images; image-to-video was added to Gen-4.5 in Jan 2026 (previously text-to-video only)
- Clips of roughly 5–10 seconds, 720p (some providers list up to 1080p), steered from a first-frame image
- More control over motion style and duration than most consumer tools

## When to Use Which

| Tool | Best For |
|------|---------|
| Weavy AI / Figma Weave | Fashion/lifestyle/ecommerce model motion |
| Kling 3.0 Image-to-Video | General high-quality animation, native audio |
| Runway Gen-4.5 | Professional production, fine control |
