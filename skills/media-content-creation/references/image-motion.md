# Animating Static Images

Tools that take a still image and add realistic motion to it.

## Weavy AI (now Figma Weave) — Motion from Photo

Adds realistic motion to a static photograph (person moves, fabric flows, hair blows).

> **Rebrand note (2026):** Figma acquired Weavy in October 2025; the product is now
> **Figma Weave**, available standalone at weave.figma.com with its own billing.
> Existing accounts/projects still work via app.weavy.ai — no action needed if you
> already use it. As of April 2026, Figma also ships 20+ reusable "Weave Workflows"
> inside Figma Community (image-to-SVG, generative variation, media production),
> reflecting deeper integration with the core Figma platform over time.

- Great for: fashion images, lifestyle photos, product ads where a model wears/uses the product
- Input: photo + motion direction prompt
- Output: short looping or progressive video clip
- Common use case: animate an ecommerce model photo → use in TikTok Shop

**Workflow:**
1. Prepare a clean product/model photo
2. Upload to Figma Weave (weave.figma.com) or app.weavy.ai
3. Describe the desired motion: "model turns and smiles", "dress flows in wind", "product rotates slowly"
4. Generate and download as MP4

## Kling "Image to Video" — High Quality Motion

Kling's image-to-video mode is also excellent for animating photos.

- URL: klingai.com → Image to Video tab
- Kling 3.0 (Turbo/Omni, launched June 17, 2026) raised image-to-video output to 2K resolution, clips up to 15 seconds, and added native multilingual audio generation
- Higher quality than many tools
- Supports longer clips from a single image

## Runway "Act-Two" / Gen-4.5

- URL: runwayml.com
- Act-Two (successor to Act One) drives character animation from a reference performance video — face, hands, and full-body gestures — mapped onto a generated image or uploaded asset
- Gen-4.5 is Runway's current top-tier generation model (Gen-3 is retired)
- Professional-grade animation from images; more control over motion style and duration
- One subscription now also grants access to third-party models in Runway's workspace (Veo 3.1, Kling, Seedance/Seedream, FLUX)

## When to Use Which

| Tool | Best For |
|------|---------|
| Figma Weave (Weavy AI) | Fashion/lifestyle/ecommerce model motion |
| Kling Image-to-Video | General high-quality animation |
| Runway | Professional production, fine control |
