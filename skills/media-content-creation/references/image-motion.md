# Animating Static Images

Tools that take a still image and add realistic motion to it.

## Figma Weave (formerly Weavy AI) — Motion from Photo

Adds realistic motion to a static photograph (person moves, fabric flows, hair blows). Figma acquired Weavy in October 2025 and rebranded it Figma Weave; the standalone app now lives at weave.figma.com (legacy app.weavy.ai logins still work, and Figma-account sign-in is now supported). A curated set of Weave tools is also available directly inside Figma Design's left panel on paid Figma plans.

- Great for: fashion images, lifestyle photos, product ads where a model wears/uses the product
- Input: photo + motion direction prompt
- Output: short looping or progressive video clip
- Common use case: animate an ecommerce model photo → use in TikTok Shop
- Free tier: 150 credits/month, up to 5 workflows (no credit card required); paid plans from $24/mo (Starter, 1,500 credits/mo)

**Workflow:**
1. Prepare a clean product/model photo
2. Upload to weave.figma.com (or via the Weave panel inside Figma Design)
3. Describe the desired motion: "model turns and smiles", "dress flows in wind", "product rotates slowly"
4. Generate and download as MP4

## Kling "Image to Video" — High Quality Motion

Kling's image-to-video mode is also excellent for animating photos.

- URL: klingai.com → Image to Video tab
- Higher quality than many tools
- Supports longer clips from a single image

## Runway Gen-4.5 Image to Video

- URL: runwayml.com
- Runway's current flagship model (Gen-4.5, unveiled Dec 2025) replaces the older Gen-3/"Act One" workflow — improved physical accuracy, realistic human movement, and cause-and-effect motion
- Image-to-video supports native 9:16 vertical (720×1280); text-to-video is 16:9-only, so for vertical text-to-video generate a still first, then route it through image-to-video
- Available on all paid plans

## When to Use Which

| Tool | Best For |
|------|---------|
| Figma Weave (Weavy) | Fashion/lifestyle/ecommerce model motion |
| Kling Image-to-Video | General high-quality animation |
| Runway Gen-4.5 | Professional production, fine control, vertical (9:16) video |
