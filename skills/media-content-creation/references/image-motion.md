# Animating Static Images

Tools that take a still image and add realistic motion to it.

## Figma Weave (formerly Weavy AI) — Motion from Photo

Adds realistic motion to a static photograph (person moves, fabric flows, hair blows). Figma acquired Weavy in October 2025 and rebranded it Figma Weave; it still runs as a standalone experience, not yet a built-in Figma Design tool. As of Config 2026, Figma announced a first integration step: paid Figma plan users can run some Weave tools directly inside Figma Design (billed on separate Weave AI credits).

- Great for: fashion images, lifestyle photos, product ads where a model wears/uses the product
- Input: photo + motion direction prompt
- Output: short looping or progressive video clip
- Common use case: animate an ecommerce model photo → use in TikTok Shop
- URL: weave.figma.com (standalone); some tools also reachable inside Figma Design for paid plans post-Config 2026

**Workflow:**
1. Prepare a clean product/model photo
2. Upload to Figma Weave (weave.figma.com)
3. Describe the desired motion: "model turns and smiles", "dress flows in wind", "product rotates slowly"
4. Generate and download as MP4

## Kling "Image to Video" — High Quality Motion

Kling's image-to-video mode is also excellent for animating photos.

- URL: klingai.com → Image to Video tab
- Higher quality than many tools
- Supports longer clips from a single image

## Runway Gen-4.5 — Professional-Grade Animation

Runway's current flagship model (released Dec 1, 2025, superseding Gen-3/Act One); included on paid plans at no extra credit cost over Gen-4.

- URL: runwayml.com
- Professional-grade animation from images; strong on physics, human motion, and camera dynamics
- More control over motion style and duration than most competitors

## When to Use Which

| Tool | Best For |
|------|---------|
| Figma Weave (formerly Weavy AI) | Fashion/lifestyle/ecommerce model motion |
| Kling Image-to-Video | General high-quality animation |
| Runway Gen-4.5 | Professional production, fine control |
